# **História do Python**

A linguagem **Python** foi desenvolvida pelo matemático e programador neerlandês Guido van Rossum, em 1989, mas publicada somente em 1991. O nome Python é uma homenagem ao programa de TV chamado "Monty Python's Flying Circus", do grupo de humor *Monty Python*.

Python é dita como:

- **Linguagem de alto nível**: Possui uma sintaxe mais próxima ao ser humano, com métodos e comandos bem definidos.
- **Linguagem interpretada**: É necessário um *interpretador* do código-fonte para que o código seja executado.
- **Linguagem imperativa**: Descreve a computação por meio de ações ou comandos para a máquina realizar.
- **Linguagem orientada a objetos**: É um paradigma da programação em que é possível abstrair conceitos do mundo real por meio de "objetos" e classes na programação.

Python também foi bastante influenciada pela linguagem ABC (utilizada na CWI, onde Guido van Rossum trabalhava) e linguagem C, principalmente na parte da sintaxe. Em contrapartida, Python foi responsável por influenciar linguagens mais modernas como Go, JavaScript, Julia, Ruby e Swift.

A versão mais adotada nos dias de hoje é *Python 3*, desconsiderando versões como *Python 3.10* ou *Python 3.11*. Foi a partir do lançamento do *Python 3* que a linguagem se popularizou e atingiu o patamar de linguagem mais utilizada.

O livro "An Introduction to Python" foi lançado por Guido van Rossum, mas para versões mais antigas, do *Python 2*. Uma opção fácil para se guiar é acessar o site oficial, [python.org](https://www.python.org/).
